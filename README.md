# FamilyVault

Secure Family Document Vault

## Features
- User Registration and Login
- Secure Authentication
- Family Document Management
- Emergency Access
- User Profile
- PostgreSQL Database
- Flutter Mobile Application
- Node.js Backend

## Technologies
- Flutter
- Dart
- Node.js
- Express.js
- PostgreSQL
- JWT
- bcrypt

## Project Structure

Family-Vault/
├── mobile/
└── backend/

## How to Run

### Backend
npm install
node server.js

### Mobile
flutter pub get
flutter run
